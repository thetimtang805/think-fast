# 从参考图反推的设计系统

> 参考来源：`reference/visual-references/` 5 张截图，一个叫 "ALt." 的咖啡馆主题作品集网站（awwwards 提名作品）。
> 这份文档不是照抄这个网站，是把它的设计语言拆解成可迁移的 token + 处理手法，再套到"即兴演讲训练工具"自己的结构上——见文末"迁移到本产品"。

## 参考图长什么样

一个"咖啡馆场景"作品集：整页是手绘线稿风格的咖啡馆插画（吧台、咖啡机、杯子、门、电话亭、黑板），双色配色（奶油底 + 深酒红线稿），偶尔用一个珊瑚红小圆点做点缀。UI 是打字机等宽字体，带一点冷幽默的文案（"选一句你的励志语录"、"没上菜单的点子"），底部一个深色胶囊形悬浮工具条，右侧一个 awwwards 提名徽标。整体感觉：**手工感、叙事感、克制的双色 + 一点点缀色，认真做但不端着**。

## 一、色彩

| 角色 | 取值 | 用途 |
|---|---|---|
| 页面底色 Cream | `#FAF3E6` | 页面背景，暖调米白，不是纯白 |
| 主墨色 Ink（酒红/焦糖棕） | `#4A1B12` | 所有线稿、文字、边框；反相时作为深色底 |
| 强调色 Accent（珊瑚红点） | `#FF6B54` | 极少量使用——一个提示圆点、一条链接文字，不做大面积填色 |
| 反相底 | 就是 Ink `#4A1B12` | 收据卡片、引语全屏这类"翻面"场景的背景 |
| 反相字 | 就是 Cream `#FAF3E6` | 反相底上的文字 |

**用色规则**：整站基本是双色（米白+酒红），强调色只用在一个地方提示"这里有动作/这是重点"，不铺色块。没有渐变、没有阴影，色彩靠"正常态 vs 反相态"制造对比，而不是靠加第三种颜色。

## 二、字体

- 全局等宽字体（打字机感），类似 JetBrains Mono / IBM Plex Mono / Space Mono。
- Logo/大标题用同一字体的加粗/加大版本，字重明显更重，制造"品牌感"而不是换字体。
- 中文场景下等宽字体对汉字本身没有等宽效果（汉字天生等宽），但数字、英文标点、拉丁字符套等宽字体依然能带出"打字机/小票"的味道——数字（比如倒计时 01:00、序号）用等宽字体差异最明显。

## 三、形状语言

| 元素 | 处理 |
|---|---|
| 线稿描边 | 统一细线宽（约 2px），线头圆润 |
| 收据/卡片类容器 | 圆角克制（约 12–16px），不是纯直角，也不是大圆角 |
| 图标按钮（info、播放、下一步） | 正圆形 |
| 悬浮工具条 | 胶囊形（radius 999），深色底，浮在场景上方 |
| 便签/引语卡片 | 顶部两个"图钉"圆点，像真的钉在墙上的纸条 |
| 分割线 | 收据风格：`----` 细虚线做小分割，`====` 双实线做大分割 |

## 四、图标与装饰

- 线性图标，描边粗细跟随插画本身（不用面性图标）。
- 常见符号：`▶` 播放、`i` 信息圆按钮、`‹ ›` 前后翻页、`≡` 菜单、`›` 圆圈里的下一步箭头。
- 装饰性细节：小圆点/短横线做"噪点"质感（洒在咖啡机、吧台上），条形码图案（收据底部），营造"真实物件"的手工感，而不是完全扁平化的图标堆砌。

## 五、文案语气

- 全部句子/标签用等宽字体 + 简短口语化英文，偶尔冷幽默（"没上菜单的点子"、"谢谢 :)"）。
- 小括号补充语气："(a café-shaped portfolio)"——克制地自我介绍，不喊口号。
- 收据卡片本身是一个彩蛋（菜单式排版：桌号、"Dine In"、条形码、"Made in Uruguay"），把"关于我"页面伪装成一张真的小票。

## 六、构图/层级

- 顶部：左侧小字幕（页面副标题）、正中 Logo、右上一个小图标（播放/开始）。
- 右侧竖排小字：作品集荣誉标签（不适用于我们，跳过）。
- 主体：大留白 + 场景插画，视觉重心偏下方（像真的站在吧台前往下看）。
- 底部悬浮：深色胶囊工具条，承载核心导航操作，常驻可见。

## 迁移到本产品：即兴演讲训练工具

这个产品没有咖啡馆场景可插画，不照搬"咖啡馆"这个意象本身，只迁移它的设计语言和手法：

1. **色彩**：直接复用 Cream + Ink + 一个珊瑚红点。珊瑚红点用在"随机话题"的提示符号上（呼应参考图里"● EACH MUG IS A PROJECT"的用法），而不是散落多处。

2. **"已选卡片"面板 → 一张收据**：这是最贴切的迁移点——用户在"点单"一样地组成自己的演讲结构。已选卡片列表改成收据卡片：深酒红底、米白等宽字体、`----` 虚线分割每一项、顶部像小票抬头一样写话题和时间，底部加一条装饰条形码或"共 N 张卡片"的合计行，呼应参考图里"THANK YOU :)"的彩蛋感，让"选完卡片准备开讲"这一刻有点仪式感。

3. **18 张卡片墙 → 贴在墙上的便签**：卡片顶部加两个小"图钉"圆点，边框保持细线描边，配合等宽字体，让每张卡片有"手写小纸条"的感觉，而不是纯粹的表单选项。

4. **倒计时练习画面 → 反相全屏引语场景**：直接复用参考图"I balance: intuition with structure"那种满屏酒红底 + 居中大号等宽字、一个圆形下一步按钮的处理——倒计时数字和"提前结束"按钮就用这套语言，营造"翻到新的一页/上台前一刻"的仪式感。

5. **底部胶囊工具条**：可以用在倒计时进行中画面的操作区（提前结束按钮），复刻参考图深色胶囊浮动条的形态。

6. **不迁移的部分**：手绘咖啡馆插画本身（工作量大且和"即兴演讲"无关的意象）、右侧的 awwwards 提名徽标（不适用）、英文冷幽默文案的具体措辞（语气可以借鉴"克制、不喊口号"，但要转译成中文、贴合添叔自己的语气，不能直译）。

## Token 速查（给实现用）

```yaml
color:
  cream: "#FAF3E6"      # 页面底色
  ink: "#4A1B12"         # 线稿/文字/正常态边框
  accent: "#FF6B54"      # 唯一强调色，只用于提示点/链接
  ink_on_cream_text: "#4A1B12"
  cream_on_ink_text: "#FAF3E6"
typography:
  family: "'JetBrains Mono','IBM Plex Mono','Space Mono',monospace"
  logo_weight: 700
  body_weight: 400
  numerals_use_mono: true   # 倒计时、序号优先吃等宽效果
radius:
  card: 14px
  pill: 999px
  icon_button: 999px        # 正圆
border:
  hairline: "1px solid var(--ink)"
  divider_dashed: "1px dashed var(--ink)"   # 收据虚线分割
  divider_solid_double: "3px double var(--ink)"  # 收据大分割
motion:
  # 参考图本身没有明显动效证据，不臆造；沿用低保真阶段"只在必要时加动效"的原则
```
