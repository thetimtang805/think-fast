# PRD: 即兴演讲训练工具

> 当前阶段：确定要做
> 最后更新：2026-08-10

## 一、为什么做

### 目标用户
添叔自己（第一阶段是个人练习工具，不对外，先验证方法本身有没有用）。

### 使用场景
添叔在需要临场组织语言表达（比如突然被点名发言、面试、公开场合即兴发表观点）时，经常缺乏准备时间，容易语无伦次、逻辑散乱。他希望在真正开口前，先用一套结构化的提问卡片，花很短时间把思路搭个骨架，再对着骨架限时练习一遍。

### 用户需求/痛点
即兴表达最大的问题不是"没话说"，而是"想到哪说到哪，没有结构"。需要一个轻量、几分钟内能用完的工具，帮自己在开口前快速搭出一条逻辑线，而不是长篇大论地做准备。

### 支撑
🟡 中 — 添叔自己有过真实体感（被突然点名发言时语无伦次过），没有做过更大范围的调研或竞品分析。

### 收益/成功标准
定性指标：添叔自己愿意主动、反复打开这个工具练习（比如临场发言前会想起来用一下），而不是用一两次就放弃。暂不设精确的使用频次数字，先看这个工具是否真的进入日常使用习惯。

## 二、怎么做

### 功能范围 (MVP)

来自 [即兴演讲训练工具-backlog.md](即兴演讲训练工具-backlog.md) 已确认的 MVP 范围：

1. 随机话题生成器（Hot Takes 分类）
2. 18 张预设思路卡片（六个家族 × 3 张审问方法，文案见 [reference/思维训练卡/思维训练卡_18张卡片内容_MVP.md](../reference/思维训练卡/思维训练卡_18张卡片内容_MVP.md)）
3. 点击卡片加入右侧已选面板
4. 已选卡片可删除
5. 已选卡片可拖拽调整顺序
6. 同一张卡片可重复添加多次
7. 已选卡片显示顺序序号
8. 源卡片区"已选"视觉标识
9. 倒计时练习（1/2/3 分钟可选）
10. 自定义模式（MVP 唯一支持的练习模式）

**明确不做（推到 Later，理由见 backlog）**：话题库扩展分类（科技/Finance/ELI5 等）、话题难度分级、Interview Prep 话题类、十位演讲高手的预设卡片顺序模式（内容已备好在 `reference/思维训练卡/思维训练卡_十位专家预设顺序.md`，等 MVP 验证完机制本身再做）。

### 页面结构
单页应用，左右两栏布局，不需要额外的导航结构：

- **左栏**：顶部话题生成器（输入框展示当前话题 + "随机生成"按钮），下方是 18 张卡片墙，按六个家族（溯因、推果、提炼、拆步、复现、定性）分组展示，每组 3 张。
- **右栏**：已选卡片面板，展示用户挑选出的卡片顺序列表，支持拖拽/删除/查看序号。

### 核心流程

1. 打开页面，点击「随机生成」，从 Hot Takes 话题池抽一个话题，显示在输入框位置。
2. 浏览 18 张思路卡片，点击任意卡片 → 该卡片以副本形式追加到右侧已选面板末尾，序号自动排到最后一位；源卡片本身保留在卡片墙上、进入"已选"视觉状态，可以继续被点击（重复添加）。
3. 在右侧面板里整理思路：拖拽调整已选卡片顺序（序号联动更新）、删除不需要的卡片、需要的话重复添加同一张卡片。
4. 思路整理好后，选择倒计时时长（1 / 2 / 3 分钟），开始计时。
5. 倒计时期间，按已选卡片的顺序即兴讲述。
6. 倒计时结束。（结束后的具体表现见下方"待确认，未展开"）

### 交互细节

**话题生成器**
- 点击「随机生成」从 Hot Takes 话题池随机抽取一条，替换输入框当前内容。
- 可重复点击换一个话题，无需额外确认。

**卡片墙 → 已选面板**
- 点击卡片 = 复制一份加入右侧列表末尾，原卡片不移除、可重复点击。
- 已选面板每项前显示阿拉伯数字序号（1、2、3…），拖拽排序后序号跟随位置实时重新计算。
- 每项提供删除入口（如 hover 时出现的删除按钮），删除后后续序号自动前移，不留空位。
- 源卡片被选中后要有区别于未选中状态的视觉样式，让用户一眼看出墙上哪些已经用过。
- 重复添加同一张卡片时，源卡片左下角用小圆点表示被选次数（点几次出现几个点），不使用数字角标——数字角标和右侧已选面板的序号圆圈视觉上容易混淆。

**倒计时**
- 提供 1 / 2 / 3 分钟三个选项，用户选定后开始计时。

**以下细节当前阶段暂不展开，进入"准备开发"阶段前需要确认（对应 backlog 里的待确认问题）：**
- 倒计时进行中的界面表现（是否还能看到已选卡片列表）。
- 倒计时结束后的表现（提示音 / 自动停止 / 能否回看这次的卡片组合）。
- 是否需要保存历史记录（话题、卡片组合、时长），方便下次回顾或复用。

## 四、关键决策

- 2026-08-10 决策：MVP 阶段只做"自定义模式"，"十位专家预设顺序模式"推迟到 Later。原因：先验证"结构化提问卡片能不能帮上忙"这个核心机制本身，专家模式是在机制验证成功之后锦上添花的第二种玩法。
- 2026-08-10 决策：目标用户先定为添叔自己一个人，收益标准是"自己愿意主动使用"。原因：这是个人项目，先用自己验证价值，跑通了再考虑要不要开放给添叔生态的学员或更广泛用户。
- 2026-08-10 决策：重复选卡的视觉表现用左下角小圆点计数，不用数字角标。原因：数字角标和已选面板的序号圆圈容易在视觉上混淆成"顺序"，圆点只表达"次数"，语义更清楚。

## 六、名词解释

- **Hot Takes**：话题库里的一个分类，指带一定观点争议性、适合快速表态的话题。
- **18 张思路卡片**：六个"审问方法"家族（溯因、推果、提炼、拆步、复现、定性）各 3 张，每张对应一种引导即兴演讲逻辑的提问方式。
- **家族**：18 张卡片的分类单位，每个家族代表组织思路的一个角度。
- **自定义模式**：MVP 唯一支持的练习模式，用户自己挑选、排序卡片；相对于 Later 阶段的"专家预设顺序模式"。
