# PRD: 即兴演讲训练工具

> 当前阶段：确定要做
> 最后更新：2026-08-11

## 一、为什么做

### 目标用户
添叔自己（第一阶段是个人练习工具，不对外，先验证方法本身有没有用）。

### 使用场景
添叔在需要临场组织语言表达（比如突然被点名发言、面试、公开场合即兴发表观点）时，经常缺乏准备时间，容易语无伦次、逻辑散乱。他希望在真正开口前，先用一套结构化的提问卡片，花很短时间把思路搭个骨架，再对着骨架限时练习一遍。

### 用户需求/痛点
即兴表达最大的问题不是"没话说"，而是"想到哪说到哪，没有结构"。需要一个轻量、几分钟内能用完的工具，帮自己在开口前快速搭出一条逻辑线，而不是长篇大论地做准备。

### 支撑
🟡 中 — 添叔自己有过真实体感（被突然点名发言时语无伦次过），没有做过更大范围的调研或竞品分析。

### 收益/成功标准
定性指标：添叔自己愿意主动、反复打开这个工具练习（比如临场发言前会想起来用一下），而不是用一两次就放弃。暂不设精确的使用频次数字，先看这个工具是否真的进入日常使用习惯。

## 二、怎么做

### 功能范围 (MVP)

来自 [即兴演讲训练工具-backlog.md](即兴演讲训练工具-backlog.md) 已确认的 MVP 范围：

1. 随机话题生成器（Hot Takes 分类）
2. 18 张预设思路卡片（六个家族 × 3 张审问方法，文案见 [reference/思维训练卡/思维训练卡_18张卡片内容_MVP.md](../reference/思维训练卡/思维训练卡_18张卡片内容_MVP.md)）
3. 点击卡片加入右侧已选面板
4. 已选卡片可删除
5. 已选卡片可拖拽调整顺序
6. 同一张卡片可重复添加多次（单张卡片最多 5 次，已选卡片总数最多 10 张，超过后对应卡片/整个卡片墙禁用）
7. 已选卡片显示顺序序号
8. 源卡片区"已选"视觉标识
9. 倒计时练习（1/2/3 分钟可选）
10. 自定义模式（MVP 唯一支持的练习模式）

**视觉方向阶段新增的几项**（原始 backlog 确认 MVP 范围时未包含，做视觉方向时补的，见下方关键决策）：

11. Header：动态标语"Think fast in ___"，四个场景自动轮播（已实现）
12. 话题生成器下方：中/英文语言切换按钮（只切换话题滚轮里的话题内容，18 张卡片和界面其余文案保持中文，已实现）
13. 话题生成器下方：日常话题/面试准备 话题分类切换按钮（已实现，激活了原本推到 Later 的 Interview Prep 话题类，先用 10 条通用面试问题打底，未按 backlog 里 Behavioral/Design/Technical 等细分类再拆分）
14. 已选卡片面板上方：专家预设顺序下拉框，默认"自定义"，选中一位专家后已选卡片直接替换成该专家的卡片顺序（已实现，激活了原本推到 Later 的十位专家预设顺序模式，见下方关键决策）

**明确不做（推到 Later，理由见 backlog）**：话题库扩展分类（科技/Finance/ELI5 等）、话题难度分级、Interview Prep 话题类按 Behavioral/Design/Technical 等细分（当前只有一份不分类的 10 条通用面试问题）。

### 页面结构
单页应用，左右两栏布局，不需要额外的导航结构：

- **顶部 Header**（高度 172px）：居中是动态标语"Think fast in ___"——固定文案"Think fast in"后面跟一个轮播场景词 + 对应插画图标，四个场景循环播放：**interviews / small talks / meetings / classrooms**（固定英文品牌元素）；两侧留白，无其他导航元素。
- **左栏**：顶部话题生成器——上方是话题滚轮（展示当前话题），下方一排 3 个按钮：中/英文语言切换、日常话题/面试准备切换、"随机生成"（触发滚轮转动）；再下方是 18 张卡片墙，按六个家族（溯因、推果、提炼、拆步、复现、定性）分组展示，每组 3 张。进入倒计时面板后，这一栏切换成发言记录文本框（详见交互细节-倒计时）。
- **右栏**：顶部是专家预设顺序下拉框（默认"自定义"），下方是已选卡片面板，展示用户挑选出的卡片顺序列表，支持拖拽/删除/查看序号；列表下方提供“快速笔记”输入框，供用户记录观点、例子或想说的一句话。

### 核心流程

1. 打开页面，点击「随机生成」，从 Hot Takes 话题池抽一个话题，显示在输入框位置。
2. 浏览 18 张思路卡片，点击任意卡片 → 该卡片以副本形式追加到右侧已选面板末尾，序号自动排到最后一位；源卡片本身保留在卡片墙上、进入"已选"视觉状态，可以继续被点击（重复添加）。
3. 在右侧面板里整理思路：拖拽调整已选卡片顺序（序号联动更新）、删除不需要的卡片、需要的话重复添加同一张卡片。
4. 思路整理好后，可在“快速笔记”中记下想法；选择倒计时时长（30 秒 / 1 / 2 / 3 分钟），点击「开始练习」。
5. 先有 5 秒准备时间（倒数 5、4、3、2、1），准备时间内也能点「提前结束」退出。
6. 准备时间结束，正式进入倒计时，按已选卡片的顺序即兴讲述；期间可随时点「提前结束」提前返回第 3 步的选卡面板。
7. 倒计时到 0，播放完成提示音（音量 50%），数字位置变成"时间到了"，下方按钮变成「重新练一次」和「返回」：
   - 「重新练一次」：用同一批已选卡片、同一个话题，重新走一遍第 5-7 步（再来一次 5 秒准备 + 正式倒计时）。
   - 「返回」：回到第 3 步的选卡面板，已选卡片和话题保留，可直接调整后再次开始。

### 交互细节

**Header 动态标语**
- 固定文案"Think fast in"+ 一个轮播场景词 + 该场景对应的插画图标（图标随场景词一起切换）。四个场景固定顺序循环：interviews → small talks → meetings → classrooms → interviews……
- 每 3 秒自动切换一次，无需用户交互触发；切换时场景词+图标一起做一次淡出淡入（约 250ms），不是硬切。
- 标语固定用英文（当作品牌元素处理，类似"Hot Takes"这类不翻译的专有名词），不跟随语言切换按钮变化。
- 素材来源：`reference/hand-drawn-essential-mini-illustrations-boldline-chapter-2-previews/` 里挑的四张手绘小图标，跟卡片墙、其余 UI 的极简黑白灰风格是两套视觉语言，只用在这一处做点缀。
- **倒计时时收起动态部分**：进入倒计时面板后，Header 只保留"Think fast"这个固定文案，"in ___"和轮播场景词/图标全部隐藏，不再切换；返回选卡面板后恢复正常轮播。场景轮播的定时器不暂停（继续在后台切换隐藏的内容），只是视觉上不显示，逻辑更简单。

**话题生成器**
- 上方是话题滚轮，展示当前话题（老虎机式滚动效果，机制仿照 speechtopicgen.com）；下方一排 3 个按钮，从左到右依次是：中/英文语言切换、日常话题/面试准备切换、"🎲 随机生成"。
- 点击「随机生成」从当前选中的话题池（日常话题 Hot Takes / 面试准备 Interview Prep）随机抽取一条，滚轮转动后停在这一条上；可重复点击换一个话题，无需额外确认。
- 语言切换按钮：**只切换话题滚轮里的内容**——话题库（日常话题/面试准备两个分类）的话题文本会跟着切换中英文。18 张卡片上的问题文本、家族名（溯因/推果…）、方法名，以及界面里所有的按钮文字、面板标题、空状态提示、时长选项、toast 提示等 UI 文案，始终保持中文，不受这个按钮影响。按钮文字显示的是"切换后会变成的语言"（当前中文时按钮显示"EN"，反之显示"中文"）。Header 的"Think fast in ___"标语也不受此按钮影响。
- 话题分类切换按钮：在"日常话题"（Hot Takes 风格的观点类话题）和"面试准备"（Interview Prep 风格的面试问答类话题）之间切换；按钮文字同样显示"切换后会变成的分类"。切换分类后滚轮重置为占位提示状态，需要重新点「随机生成」抽话题。

**卡片墙 → 已选面板**
- 点击卡片 = 复制一份加入右侧列表末尾，原卡片不移除、可重复点击。
- 已选面板每项前显示阿拉伯数字序号（1、2、3…），拖拽排序后序号跟随位置实时重新计算。
- 每项提供删除入口（如 hover 时出现的删除按钮），删除后后续序号自动前移，不留空位。
- 源卡片被选中后要有区别于未选中状态的视觉样式，让用户一眼看出墙上哪些已经用过。
- 重复添加同一张卡片时，源卡片左下角用小圆点表示被选次数（点几次出现几个点），不使用数字角标——数字角标和右侧已选面板的序号圆圈视觉上容易混淆。圆点数量封顶（超过 8 个只显示 8 个），避免选很多次时圆点溢出卡片边界；精确次数始终能在右侧已选面板里数出来，圆点只是"选过不止一次"的提示，不追求精确计数。
- **选卡数量限制**：单张卡片最多重复添加 5 次；已选卡片总数最多 10 张。达到单卡上限时，只禁用这一张卡片（其他卡片仍可点击），按钮变灰、鼠标停留显示"这张卡片最多选 5 次"；达到总数上限时，禁用卡片墙上所有卡片（不管是否已选过），提示"最多选 10 张卡片"。已选面板标题旁常驻显示"当前数 / 10"的计数，让用户随时知道还能再选几张。删除已选卡片会立刻释放对应额度，被禁用的卡片重新变回可点击。
- **一键清除**：计数器右边有一个小的"清除"文字按钮，只在已选卡片非空时显示；点击后清空全部已选卡片、专家下拉框跳回"自定义"，并弹出撤销 toast（跟单张删除共用同一套撤销机制，5 秒内可撤销恢复清空前的完整列表）。
- **快速笔记**：已选卡片列表下方提供“快速笔记”多行输入框，可记录观点、例子或想说的一句话；输入框高度会随内容自动向下展开。开始练习或“再练一次”时，笔记内容会预填入左栏的“你的发言记录”输入框，用户可在其后继续补写；笔记在当前页面会话中保留，刷新页面后重置。

**专家预设顺序**
- 已选卡片面板正上方是一个下拉框，默认值"自定义"，点开后是十位专家的名字（Steve Jobs、Simon Sinek、Don Draper、Feynman、Obama、Seth Godin、Naval Ravikant、Brené Brown、Chris Voss、Harari），顺序内容见 [reference/思维训练卡/思维训练卡_十位专家预设顺序.md](../reference/思维训练卡/思维训练卡_十位专家预设顺序.md)。
- 选中一位专家：清空当前已选卡片，替换成该专家的预设卡片顺序（卡片数量、顺序、重复次数都严格按参考文档来，8 位专家用了 5-6 张，Jobs 用 8 张，Obama 用 7 张，均在 10 张总量上限、单卡 5 次上限之内，不会触发选卡数量限制）；左侧卡片墙的"已选"视觉标识、圆点计数同步刷新，跟自定义模式点选的效果完全一样。
- 手动把下拉框切回"自定义"（不是被动跳回，是用户自己选的）：清空已选卡片，效果等同于点了"清除"按钮，同样弹撤销 toast。
- 只要用户手动做任何一次选卡相关操作——点卡片新增、删除已选卡片（含撤销）、拖拽调整顺序——下拉框自动跳回"自定义"，因为已选内容已经不再是那个专家的原始顺序。反过来，下拉框停在专家名字上，就代表当前已选卡片跟该专家的预设完全一致。
- 这不是锁定模式：选完专家预设后依然可以在此基础上继续增删改，效果等同于先用专家预设当起点、再手动调整（对应 backlog 里"专家模式的可编辑性"这条待确认问题——选择的实现是"可编辑"，不锁定）。

**倒计时**
- 提供 30 秒 / 1 / 2 / 3 分钟四个选项，用户选定后点击「开始练习」进入倒计时面板，面板分三个阶段：**准备 → 正式倒计时 → 时间到**。
- **准备阶段**（固定 5 秒）：大数字位置显示 5、4、3、2、1 的个位数倒数（不是 mm:ss 格式），上方有一行小字"准备开始"标明这是准备时间而不是正式计时；话题文本和已选卡片列表提前展示（不用等准备结束才显示），方便边准备边过一遍思路。5 秒结束自动无缝进入正式倒计时，不需要用户操作。
- **正式倒计时阶段**：大数字变成 mm:ss 格式的正式倒计时；下方持续展示当前话题文本（即开始练习时话题滚轮上停留的那条话题，不加"抽中的问题"之类的标签前缀），再下方完整展示已选卡片的顺序列表（只读，不可拖拽/删除/重新添加），方便照着讲。
- 准备阶段和正式倒计时阶段都提供「提前结束」入口，点击后不做提示音，直接返回选卡面板，已选卡片和话题保留，不弹出单独的确认画面。
- **发言记录输入框**：进入倒计时面板后，左栏（平时是卡片墙的位置）切换成一个"你的发言记录"文本框，占位提示"可以打开手机自带的语音输入法，边讲边把内容打在这里…"；用户可以用手机/系统自带的语音转文字输入法，边即兴讲边把内容实时打进这个框，作为练习后回看的记录。每次开始练习或点「重新练一次」，输入框会先填入“快速笔记”的当前内容，用户可继续补写；点「提前结束」或「返回」离开倒计时面板时，输入框内容不做保存，回到卡片墙视图。
- 倒计时面板的左右栏宽度比例和平时相反：平时是左栏（卡片墙）60% / 右栏（已选面板）40%，练习时改成左栏（发言记录输入框）40% / 右栏（倒计时模块）60%——倒计时模块信息更多（大数字、话题、卡片顺序列表、按钮），需要更宽的空间；发言记录只是辅助性的记录区，不需要占大头。
- **时间到阶段**：正式倒计时到 0 后，播放一次完成提示音（音量 50%），大数字位置的文字变成"时间到了"（话题和已选卡片列表继续保留展示），下方按钮从「提前结束」换成两个新按钮：
  - 「重新练一次」：用同一批已选卡片、同一个话题，原地（不返回选卡面板）重新走一遍准备阶段 + 正式倒计时阶段。
  - 「返回」：回到选卡面板，已选卡片和话题保留，可直接调整后再次开始，效果等同于之前的自动返回。

**历史记录**
- 不做历史记录、不做本地持久化。刷新页面后话题和已选卡片都会重置，下次要重新抽话题、重新选卡。这是确认过的 MVP 范围决定，不是待定项。

## 四、关键决策

- 2026-08-10 决策：MVP 阶段只做"自定义模式"，"十位专家预设顺序模式"推迟到 Later。原因：先验证"结构化提问卡片能不能帮上忙"这个核心机制本身，专家模式是在机制验证成功之后锦上添花的第二种玩法。**（2026-08-11 更新：专家模式已提前实现，见下方 2026-08-11 决策）**
- 2026-08-10 决策：目标用户先定为添叔自己一个人，收益标准是"自己愿意主动使用"。原因：这是个人项目，先用自己验证价值，跑通了再考虑要不要开放给添叔生态的学员或更广泛用户。
- 2026-08-10 决策：重复选卡的视觉表现用左下角小圆点计数，不用数字角标。原因：数字角标和已选面板的序号圆圈容易在视觉上混淆成"顺序"，圆点只表达"次数"，语义更清楚。
- 2026-08-10 决策：倒计时进行中保留已选卡片列表可见（只读）；倒计时结束不做提示音，直接自动返回选卡面板，不做单独的"结束"确认画面；不做历史记录/本地持久化。原因：这是个人练习工具，流程越轻越好，先验证核心机制，持久化和更精细的结束反馈等确认有用了再加。
- 2026-08-11 决策：Header 加一条动态标语"Think fast in ___"，场景词确定为 interview、small talks、meetings、classrooms 四个。原因：先脑暴了 interview/meetings/negotiations/networking/debates 等职场向场景，又补了 toasts/classrooms/panels/client calls/press/dates 等更生活化的场景；最终选定的四个覆盖了面试、社交、职场会议、课堂四类不同情境，且长度、语气统一。曾考虑用"improv"替代 classrooms，但 improv 本身已经是"临场发挥"的意思，跟"Think fast"语义重复，最终弃用。

## 六、名词解释

- **Hot Takes**：话题库里的一个分类，指带一定观点争议性、适合快速表态的话题。
- **18 张思路卡片**：六个"审问方法"家族（溯因、推果、提炼、拆步、复现、定性）各 3 张，每张对应一种引导即兴演讲逻辑的提问方式。
- **家族**：18 张卡片的分类单位，每个家族代表组织思路的一个角度。
- **自定义模式**：用户自己挑选、排序卡片，对应已选卡片面板专家下拉框的"自定义"选项；相对于"专家预设顺序模式"（选中专家后套用其预设卡片顺序，可在此基础上继续编辑）。
